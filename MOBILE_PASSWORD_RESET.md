# Mobile App - Password Reset Feature

## Overview
Password reset functionality has been added to the Aflon Mark mobile app, allowing users to reset their passwords directly from the sign-in screen.

## Features Implemented

### 1. Forgot Password Screen
Users can request a password reset link from the login screen.

**Flow:**
1. User taps "Forgot Password?" link on login screen
2. Navigates to forgot password screen
3. Enters their email address
4. System sends reset link to email (if account exists)
5. User receives confirmation message
6. User can return to login screen

**File:** `mobile-app/app/(auth)/forgot-password.tsx`

**Features:**
- Clean, branded UI matching login screen
- Email validation
- Loading states
- Success/error handling
- Back button to return to login
- Network error handling

### 2. Reset Password Screen
Users can set a new password using the reset link from their email.

**Flow:**
1. User clicks reset link in email
2. Opens mobile app with reset token
3. Navigates to reset password screen
4. Enters new password (min. 8 characters)
5. Confirms password
6. Password is updated
7. User is redirected to login screen

**File:** `mobile-app/app/(auth)/reset-password.tsx`

**Features:**
- Password visibility toggle (eye icon)
- Password confirmation field
- Minimum 8 character validation
- Password match validation
- Token validation
- Expired token handling
- Loading states
- Success/error handling

### 3. Updated Login Screen
Added "Forgot Password?" link to the login screen.

**File:** `mobile-app/app/(auth)/login.tsx`

**Changes:**
- Added "Forgot Password?" link next to password label
- Link navigates to forgot password screen
- Maintains existing login functionality

## API Integration

### Endpoints Used
1. **POST /api/auth/forgot-password**
   - Request body: `{ email: string }`
   - Sends reset link to user's email
   - Returns success message

2. **POST /api/auth/reset-password**
   - Request body: `{ token: string, password: string }`
   - Validates token and updates password
   - Returns success message

### Error Handling
- **Network Errors** (status 0): "Connection Error" - Check your connection
- **API Errors** (4xx/5xx): Displays specific error message from backend
- **Validation Errors**: Client-side validation before API call

## Security Features

1. **Token-Based Reset**: Secure tokens generated by backend
2. **Token Expiry**: Tokens expire after 1 hour (backend enforced)
3. **One-Time Use**: Tokens are invalidated after successful reset
4. **Password Requirements**: Minimum 8 characters enforced
5. **Password Confirmation**: Users must confirm new password
6. **Clear Error Messages**: Users know if email exists or not for better UX

## Deep Linking Support

The reset password screen supports deep linking via URL parameters:
- URL format: `aflonmark://reset-password?token=RESET_TOKEN`
- Token is extracted from URL query parameters
- Invalid tokens show error and redirect to login

## Troubleshooting

### Reset link not working
- Check if token has expired (>1 hour)
- Verify backend URL is correct in `.env`
- Check if email was sent successfully

### Email not received
- Check spam/junk folder
- Verify SMTP settings in backend
- Confirm email address is correct

### App not opening from email link
- Verify deep linking is configured in `app.json`
- Check URL scheme matches: `aflonmark://`
- Test with a different email client

### Password reset fails
- Ensure password is at least 8 characters
- Verify passwords match
- Check network connection
- Confirm token hasn't been used already
